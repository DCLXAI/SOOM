# Changelog

All notable user-visible changes to SOOM are recorded here. This project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) and uses the format
described by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Apache-2.0 project license and separate trademark policy.
- Contributor, conduct, security, privacy, and third-party notice documents.
- Public-source CI, dependency update configuration, and release-readiness gate.

### Security

- Defined release invariants for local-only recording, BYOK processing, input
  redaction, screen-only AI evidence, and sensitive diagnostics.

## [0.6.0] - 2026-08-14

Internal development snapshot; it was not an official notarized public release.

### Added

- macOS menu-bar recorder for display, window, region, camera-only, and
  screenshot capture modes.
- Face-camera composition, microphone and system-audio recording, click
  evidence, session journal, recovery, and a local session library.
- BYOK transcription and structured TaskSpec/agent handoff generation.
- Experimental optional share web application and transcoder components.
